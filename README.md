# 余烬之光

一个横屏浏览器物理堆叠闯关小游戏。玩家从物料库拖出废弃物，搭建稳定高塔并拉下替代太阳的拉绳；全程使用原创回收机器人“拾光者”。

## 怎么玩

- 从右侧垃圾物品库按住物件，拖到中央建造区后松手；地面任意位置都可作为基础。
- 已放下的物件可再次按住并拖动，调整重心、底座和堆叠高度；物理模拟会在松手后恢复。
- 左侧高度尺显示当前高度与带具体数值的目标刻度；到达黄色短目标线后，需要让高塔静止片刻并实际接近绳端。
- 右上角的 `↻` 可重新开始本关；倒塌后也可无限重试。
- 达标后才会出现原创双足机器人“拾光者 R-07”：它拉下随关卡高度上移的短绳，人工太阳启动后，废土场景会交叉淡入植被复苏状态。
- 初始目标为 8m，最高目标为 99m；通关后直接进入下一关。

## 本地运行

需要 Node.js 22+ 与 pnpm：

```bash
pnpm install
pnpm run dev
```

验证生产构建：

```bash
pnpm run build
```

## 已实现范围

- 10 关：8 / 12 / 17 / 28 / 40 / 54 / 69 / 81 / 91 / 99m
- Matter.js 2D 刚体、摩擦、重力、滚动物件与高处侧风
- 拖入物件、已放下物件的二次拖动调整、稳定高度、倒塌、重试和连续关卡
- 写实废土 / 复苏双场景、现实废品图集和同源物料库缩略图
- 随目标高度移动的人工太阳灯具、固定短绳与真实绳端可达判定
- 达标后才出场的原创“拾光者 R-07”、拉绳、光源点亮与植被生长演出
- 桌面端三栏布局与移动端场景、横向高度尺、横向垃圾物品库布局

本项目是可玩的网页原型；正式商业版还应增加更多经过逐机测试的关卡种子、音效、素材授权和移动设备性能调优。
