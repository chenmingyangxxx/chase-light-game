# 余烬之光

一个横屏浏览器物理堆叠闯关小游戏。玩家从物料库拖出废弃物，搭建稳定高塔并拉下替代太阳的拉绳；全程使用原创回收机器人“拾光者”。

## 怎么玩

- 按住右侧物料卡，拖到中央建造区后松手。
- 已选中物料时，可用界面按钮或键盘 `Q / E` 每次旋转 15°。
- 左侧高度仪显示实时高度与稳定记录；到达黄色目标线后，需要让高塔静止片刻。
- 每关有 3 次明确提示；倒塌后可无限重试。
- 通关自动解锁下一关，最高目标为 99m；进度保存在当前浏览器中。

## 本地运行

需要 Node.js 22+ 与 pnpm：

```bash
pnpm install
pnpm run dev
```

验证生产构建：

```bash
pnpm run build
```

## 已实现范围

- 10 关：3 / 5 / 8 / 14 / 23 / 35 / 50 / 68 / 83 / 99m
- Matter.js 2D 刚体、摩擦、重力、滚动物件与高处侧风
- 拖拽、旋转、物料回收、稳定高度、倒塌、重试、提示和关卡解锁
- 塔顶拉绳、原创机器人、光源点亮与荒地复苏演出

本项目是可玩的网页原型；正式商业版还应增加更多经过逐机测试的关卡种子、音效、素材授权和移动设备性能调优。
